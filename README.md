# Voxel-движок на Bend 2

Проект движка для мелких разрушаемых вокселей. Текущий этап — архитектура; запускаемой сцены пока нет.

- [Архитектура и порядок реализации](docs/architecture.md)
- [Проверка возможностей Bend и CUDA на текущем ПК](docs/bend-feasibility.md)
- [Словарь модели мира](CONTEXT.md)

Предлагаемая основа: разреженное воксельное хранилище, отдельные тела для обломков, кешируемая поверхность и адаптер [Bend3D](https://github.com/bendlang/bend/blob/a49524265bdfa5753a4bf38e25f0574a705dd868/demos/app_slash_boss_3d/bend3d.bend).

Локальный Bend — 2.0.16. Минимальный CUDA-вызов проверен на GTX 1660; при сборке требуется `CUDA_HOME=/opt/cuda`. Это не замер производительности движка.
